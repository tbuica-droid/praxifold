# Praxifold design context

The Vite learning studio uses warm paper surfaces, ultramarine actions and a separate dark palette. Shared tokens live in `style.css`. The folded mark and path illustrations live in `mark.svg` and `art.js`.

Placement uses the studio’s existing action links, native radio choices and disclosures. Critical question text uses the theme’s ink color. Prompts, evidence, numbers, units and choices use medium or heavier type. Keep explanatory copy close to the decision it supports.
